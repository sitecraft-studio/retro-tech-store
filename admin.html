Как подключить Firebase и защитить админку
  1. Создайте проект на console.firebase.google.com (тариф Spark бесплатный).
  2. Включите Firestore Database в режиме Production, Storage и Authentication → Sign-in method → Email/Password.
  3. В Authentication → Users создайте администратора с email admin@retro.ru. Если нужен другой email, измените константу ADMIN_EMAIL в admin.html и email в правилах allow write ниже.
  4. Откройте Project settings → Your apps → Web </>, скопируйте firebaseConfig и вставьте значения в файл firebase-config.js.
  5. В Firestore → Rules опубликуйте правила ниже. Они разрешают чтение каталога и названия магазина всем, а запись — только администратору.
  6. В Storage → Rules опубликуйте правила для загрузки фото. Читать фото смогут все, загружать — только администратор.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{productId} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'admin@retro.ru';
    }
    match /settings/{settingId} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'admin@retro.ru';
    }
  }
}
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /products/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'admin@retro.ru';
    }
  }
}

Для GitHub Pages добавьте домен ВАШ_ЛОГИН.github.io в Authentication → Settings → Authorized domains. Пароль демо-режима admin123 работает только пока Firebase не настроен и не защищает реальные данные.
